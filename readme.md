# Deadlocks as Runtime Exceptions

This repository contains the LaTeX sources for Rafael Brandão Lôbo's master's
thesis on deadlock exceptions and related research papers. The research explores
detecting deadlocks at runtime and reporting them as exceptions to help developers
identify and diagnose concurrency bugs, with a focus on Java deadlocks involving
two threads and two locks.

The thesis sources are in [`msc/`](msc/), and related paper sources are in the
repository root and [`conf/`](conf/).
